# 世博 A 地块 3D Demo

在线演示：https://tangx912.github.io/shibo-a-block-demo/

上海浦东周家渡一带的本地浏览器 3D 场景。场景将上传的航拍标注图作为空间关系参照，并补画黄浦江、白莲泾、片区道路、世博地标和办公楼宇体块。

## 运行

```bash
npm install
npm run dev
```

终端会显示本地访问地址，通常是 `http://localhost:5173`。

## 浏览与交互

- 鼠标左键拖动旋转，滚轮缩放，右键拖动平移。
- 点击楼宇或地块显示名称和简要信息；浦银中心 A 至 G 座分别可选。
- 左侧开关控制楼宇、楼名和道路名；右下按钮回到总览。
- 「绿谷」作为浦银中心 A 至 G 座的组团范围显示；不重复建一套组团楼体。
- 中华艺术宫按原世博中国馆的标志性层叠外形建模；世博展览馆、世博轴、梅赛德斯-奔驰文化中心作为核心场馆参照。

## 数据说明

上传的 Google Maps 航拍标注图用于对照楼群的相对位置。场景当前为白模展示 Demo：单栋楼的建筑红线、朝向、尺寸和高度是基于该图与公开地名信息所作的示意重建，不是测绘数据；道路走向、水岸线和街区尺寸也作了简化，细节需要对照高分辨率底图继续校正。没有将航拍图或商业地图瓦片打包进项目。

## 技术

Three.js + Vite；运行不需要地图服务或付费 API Key。Three.js 作为 npm 依赖本地打包。

## 发布

`npm run build` 生成 `dist/`，使用相对资源路径以兼容 GitHub Pages 子目录。
GitHub Pages 从 `gh-pages` 分支的根目录发布；更新演示时需将新的 `dist/` 内容提交到该分支。
